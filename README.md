## Overview

Ppalli explores contemporary brand design, kinetic motion graphics, and bleeding-edge frontend tooling. It features responsive micro-animations, accessible interaction primitives, and dark-mode styling deployed globally via Cloudflare Pages edge network.

## Features

- **Kinetic Micro-Interactions**: Fluid layout transitions and shader-level responsiveness.
- **Accessible Design Primitives**: Built with Radix UI headless components for complete keyboard and screen reader accessibility.
- **Tailwind CSS v4 Utility Engine**: Clean, minimal, zero-runtime CSS tokens.
- **Instant Edge Delivery**: Hosted on Cloudflare Pages with sub-second time-to-interactive.

## Tech Stack

- **Framework**: TanStack Start / React 19 / Vite
- **Styling**: Tailwind CSS v4 + Radix UI
- **Deployment**: Cloudflare Pages / Nitro Edge Runtime
